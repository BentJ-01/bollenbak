# Bollenbak — digitaal bierboekje

Digitaal bierboekje voor de bieravond van de smoutebollenbak van Scouts Vosselaar.

- Statische site, geen build nodig: `index.html`, `bieren.js` en `img/`.
- Bieren aanpassen: `bieren.js`. Flesfoto's: `img/bieren/<naam-als-slug>.webp` (bv. `sint-bernardus-prior-8.webp`).
- Link naar één bier: `…/bollenbak/#12`.
- Gehost via GitHub Pages (Settings → Pages → Deploy from a branch → `main` / root).

Lokaal bekijken: `python3 -m http.server` en open `http://localhost:8000/`.
